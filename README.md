# موزیک رندوم — Telegram Mini App (نسخه‌ی کاملاً رایگان)

این پروژه بدون هیچ سرور همیشه‌روشنی کار می‌کنه: فرانت‌اند + بک‌اند هر دو روی
Vercel (رایگان) هستن، و ذخیره‌سازی هم روی Upstash Redis (رایگان) است.

## معماری خیلی خلاصه

```
تلگرام (Webhook) → Vercel Serverless Functions (api/*.py) → Upstash Redis
                                    ↓
                          فایل صوتی از Telegram File API
                                    ↑
                          index.html (مینی‌اپ) در مرورگر کاربر
```

---

## مرحله ۰ — امنیت: ابطال توکن قدیم (حتماً اول این کار رو بکن)

توکن قبلی بات (`8020647795:...`) قبلاً به‌صورت متن ساده جایی به اشتراک
گذاشته شده و باید غیرقابل‌اعتماد در نظر گرفته بشه.

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. `/mybots` → بات خودت رو انتخاب کن → `API Token` → `Revoke current token`.
3. توکن جدید رو یه جای امن نگه دار (فقط در Environment Variables، هیچ‌جای دیگه).

## مرحله ۱ — ساخت دیتابیس رایگان Upstash Redis

1. برو به [upstash.com](https://upstash.com) و با گیت‌هاب/گوگل ثبت‌نام کن (رایگان).
2. یک دیتابیس Redis جدید بساز (نزدیک‌ترین Region به کاربرات رو انتخاب کن).
3. از تب **REST API** دو مقدار رو کپی کن:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`

## مرحله ۲ — ساخت کانال رله (Relay Channel)

این کانال فقط برای خود پروژه‌ست، لازم نیست عمومی باشه.

1. یک کانال تلگرام جدید و **خصوصی** بساز (مثلاً «Music Relay»).
2. باتت رو به این کانال اضافه کن و **ادمین** کن (فقط دسترسی «ارسال پیام» کافیه).
3. یوزرنیم یا آیدی عددی این کانال رو یادداشت کن (برای indexer لازمه).

## مرحله ۳ — بالا بردن پروژه روی GitHub + Vercel

1. یک ریپازیتوری جدید در گیت‌هاب بساز و همه‌ی فایل‌های این پروژه (به‌جز
   پوشه‌ی `indexer/` که لازم نیست دیپلوی بشه، ولی اشکالی هم نداره بمونه)
   رو push کن.
2. در [vercel.com](https://vercel.com) پروژه رو از روی همین ریپو Import کن.
3. در **Settings → Environment Variables** این‌ها رو اضافه کن:
   - `BOT_TOKEN` = توکن جدید بات
   - `WEBHOOK_SECRET` = یک رشته‌ی تصادفی دلخواه (مثلاً با `openssl rand -hex 20`)
   - `WEB_APP_URL` = آدرسی که Vercel بهت می‌ده (مثلاً `https://your-app.vercel.app`)
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
4. Deploy بزن.
5. مطمئن شو که با باز کردن آدرس Vercel در مرورگر، صفحه‌ی پلیر (تیره،
   گلس‌مورفیسم) واقعاً نمایش داده می‌شه — نه صفحه‌ی خالی.

## مرحله ۴ — وصل کردن بات به این دیپلوی (تنظیم Webhook)

روی کامپیوتر خودت (پایتون استاندارد کافیه، نیازی به نصب چیزی نیست):

```bash
BOT_TOKEN="توکن جدید" \
WEBHOOK_SECRET="همون رشته‌ی مرحله‌ی قبل" \
WEB_APP_URL="https://your-app.vercel.app" \
python set_webhook.py
```

اگه پیام `"ok":true` گرفتی، یعنی موفق بوده. حالا در تلگرام به بات
`/start` بزن — باید دکمه‌ی «🎧 پخش رندوم موزیک» رو ببینی.

## مرحله ۵ — ایندکس کردن آهنگ‌های قدیمی کانال منبع

```bash
cd indexer
pip install -r requirements.txt

TELEGRAM_API_ID="..." \
TELEGRAM_API_HASH="..." \
SOURCE_CHANNEL="@channel_manba" \
RELAY_CHANNEL="@channel_role_khodet" \
python build_index.py
```

- `TELEGRAM_API_ID` و `TELEGRAM_API_HASH` رو از
  [my.telegram.org](https://my.telegram.org) رایگان می‌گیری (با اکانت
  شخصی خودت، نه بات).
- دفعه‌ی اول ازت شماره موبایل و کد تایید می‌خواد؛ بعدش یک فایل session
  کنار اسکریپت می‌سازه که دیگه لازم نیست دوباره لاگین کنی.
- این اسکریپت هر آهنگ رو از کانال منبع به کانال رله فوروارد می‌کنه؛ به
  محض رسیدن هر پیام به کانال رله، Webhook خودکار متادیتاش رو در Redis
  ذخیره می‌کنه. برای کانال‌های بزرگ ممکنه چند دقیقه طول بکشه (عمداً بین
  هر فوروارد کمی مکث می‌کنه تا تلگرام محدودمون نکنه).

## مرحله ۶ — تست نهایی

1. در تلگرام روی دکمه‌ی «پخش رندوم موزیک» بزن تا مینی‌اپ باز بشه.
2. باید یک آهنگ رندوم لود بشه، دکمه‌ی پخش کار کنه، و دکمه‌ی دانلود فایل
   رو دانلود کنه.
3. اگه پیام «هنوز هیچ آهنگی ایندکس نشده» دیدی، یعنی مرحله‌ی ۵ هنوز کامل
   نشده یا Webhook درست ست نشده.

---

## نکات مهم برای بعد

- **امنیت بیشتر (اختیاری، توصیه‌شده):** الان هر کسی که آدرس Vercel رو
  داشته باشه می‌تونه به `/api/random` درخواست بزنه، نه فقط کاربران واقعی
  تلگرام. قدم بعدی طبیعی اینه که مقدار `initData` که تلگرام به Mini App
  می‌ده رو با HMAC و `BOT_TOKEN` در بک‌اند اعتبارسنجی کنیم. اگه خواستی
  همین الان اضافه‌اش می‌کنم.
- **مقیاس:** پلن رایگان Upstash و Vercel برای شروع و حتی چند صد کاربر
  فعال کاملاً کافیه؛ اگه پروژه بزرگ شد، اول چیزی که باید ارتقا بدی
  همین دوتاست.
- **آهنگ‌های جدید بعدی:** از این به بعد هر پستی که مستقیم در کانال رله
  گذاشته بشه (یا از کانال منبع فوروارد بشه) خودکار ایندکس می‌شه؛ نیازی
  به اجرای دوباره‌ی `build_index.py` نیست مگر بخوای یک کانال منبع دیگه
  رو هم اضافه کنی.
